# VisionMate 
An app that aids visually impaired individuals in navigating safely in their surroundings, such as outdoor and indoor spaces 🏞️🏢, providing essential assistance for independent mobility and bringing all accessibility features on one unified platform 🚶‍♂️📱. 

## ✨ App Highlights 
*  **Smart Assistance**: Object Detection, Distance & Depth Estimation, Fall Detection
*  **User Experience**: Multilingual Interface, Speech Navigation
*  **Safety & Connectivity**: SMS & Emergency Calling, Location Tracking
*  **Security**: User Authentication (Fingerprint)
  
## ⚙️ Technologies Used
*  **Frontend**: Expo 53, React Native, TypeScript
*  **AI/ML**: TensorFlow, Ultralytics YOLOv8, PyTorch, Python
*  **Backend**: Firebase, WebSocket, Twilio

## 🌟 Impact 
Empowering visually impaired individuals with independent, safe, and confident mobility.
